# Cooltime

AI・API・MCP の**利用制限が「あと何分・何時間で戻るか」**を、Mac のメニューバーで確認するアプリです。
稼働状況の監視ではなく、「使い切った後、いつ戻るか」を知るためのものです。

- メニューバーには、一番早く戻るもの 1 件だけを「あと43分」の形で出します（カプセルで他のアイコンと区別）。
- クリックすると、**制限中 / 使用可能 / クレジット** の一覧が開きます。
- **起動すると、この Mac でログイン済みの Claude Code と Codex を自動で見つけて追加します**（メールアドレス・プランも自動で入ります）。
  自分で削除したものは、戻しません。APIキー系のサービスだけは、「管理…」から自分で追加します。
- macOS 14 以降。Dock にアイコンは出ません。

## インストールと更新

**初回**
1. [Releases](../../releases) から `Cooltime.zip` をダウンロードして展開します。
2. `Cooltime.app` を「アプリケーション」に移します。
3. 署名・公証をしていない個人配布のため、初回は macOS に止められます（マルウェアが見つかったという意味ではありません）。
   「ゴミ箱に入れる」は押さず、「完了」で閉じてから、次のどちらかで開きます。
   - 「システム設定」→「プライバシーとセキュリティ」→ 下の方の「"Cooltime" は開くことがブロックされました」の「このまま開く」
   - ターミナルで `xattr -dr com.apple.quarantine /Applications/Cooltime.app` を実行してから、もう一度開く

   macOS 14 以前は、右クリック →「開く」でも開けます。

**更新（次の版から）**
- 「管理…」の左下の「更新を確認」を押すと、GitHub のリリースの新しい版を確認します。新しい版があれば「○○ に更新して再起動」を押すだけです。
- アプリ自身がダウンロードするので、**上の警告は出ません**（手順3は、初回だけです）。
- 確認も、ダウンロードも、ボタンを押したときだけです。通信先は、このアプリの GitHub のリリースだけで、ダウンロードしたファイルは、GitHub が付けるハッシュと照合してから入れ替えます。
- 「アプリケーション」など、書き込める場所に置いたアプリが対象です。
- **リポジトリが公開されている必要があります。** 非公開のままだと、アプリはログインできないので、リリースを見つけられません（「HTTP 404」と出ます）。非公開のあいだは、GitHub のリリースのページから、zip をダウンロードして入れてください。

## 取得できるサービス

| サービス | 取得方法 | 通信 |
|---|---|---|
| Claude / Claude Code（Pro・Max） | 公式の Claude Code の `/usage`（5時間・週）。ステータスラインの記録も併用 | 1分おきと、返事が終わった合図のとき（Claude Code 自身が通信） |
| ChatGPT / Codex | `codex app-server` への問い合わせ（5時間・週、クレジット） | 1分おき（失敗が続くときは5分おき）と、更新ボタン |
| ElevenLabs | 公式 API（月の文字数・次のリセット） | 更新ボタンのときだけ |
| Firecrawl | 公式 API（月のクレジット・請求期間の終了） | 更新ボタンのときだけ |
| Vercel AI Gateway / OpenRouter / DeepSeek | 公式 API（残高。OpenRouter は上限付きキーのみ） | 更新ボタンのときだけ |

戻る時刻を正確に取れないもの（Figma MCP、API 課金の Claude Code、Lovable、Netlify、Midjourney、
Anthropic / OpenAI API のレート制限など）は載せていません。推定の数字も出しません。
v0・Cursor は検証待ちのため、今回は入れていません。

## Claude の使用量の取り方

Claude の利用枠は、Claude アプリ・デスクトップの Code タブ・ターミナル版で共有されています。
Cooltime は、**公式の Claude Code（ターミナル版）に `claude -p "/usage"` を実行させ**、その表示（5時間枠・週の枠の残りと戻り時刻）を読みます。

- Cooltime は、Claude のログイン情報に触れません。問い合わせるのは、改変していない Claude Code 自身です。
- `/usage` は会話ではないので、利用枠は減りません。
- 起動時と、1分おきに、自動で確認します（失敗が続くときは5分おき）。「すべて更新」を押すと、その場で最新にします。
- ターミナル版の Claude Code が入っていて、ログイン済みである必要があります（`claude` を実行して `/login`）。

### 使った直後に、すぐ更新する

Cooltime は、Claude Code（ターミナルでもデスクトップの Code タブでも）と Codex が、会話の記録のファイル
（`~/.claude/projects`・`~/.codex/sessions`）を更新したことだけを知り、返事が終わって5秒ほど経ったら、そのサービスだけすぐ更新します。
**ファイルの中身は読みません**（更新があったことだけを見ます）。

### 返事が終わるたびに、すぐ更新する（ターミナル版・ボタン1つ）

「管理…」→ Claude →「設定する…」を押すと、`~/.claude/settings.json` に次の2つを足します。変更前・変更後を確認してから設定し、元のファイルは `settings.json.cooltime-backup-…` として残ります。「元に戻す」でいつでも外せます。

- **Stop フック**: デスクトップの Code タブでもターミナルでも、返事が終わったら、Cooltime に合図します（手元のファイルを更新するだけで、通信はしません）。合図を受けると、すぐに使用量を確認します。
- **ステータスライン**: ターミナル版を使っているときは、画面に渡される使用量も記録します。すでにステータスラインがある場合は、壊さずに表示も続けます。

Claude のアカウントが複数あるときは、ステータスラインの記録だけが使えます。アカウントごとに環境変数 `COOLTIME_SLOT`（例: `work`）を変え、管理画面の「取得元の識別名」に同じ名前を入れます。

## 振り返り

ポップオーバーの「📊」か、管理画面の「振り返り」から開きます。日・週・月ごとに、次を見られます。

- 制限に当たった回数と、制限で待った時間
- 週の枠の使い切り率と、使い残し（リセットの直前まで記録できた週だけ。記録できていない週は「—」）
- 月額（管理画面で、自分で入れたとき）
- **おばけ積み**: いつ使ったか（日は1時間ごと、週・月は1日ごと）を、おばけを積み上げて見せます。1匹が「週（月）の枠の ○% 分」です。上限に当たった日は、赤いおばけになり、いちばん上のおばけが眠ります。使っていない日は、薄いおばけが眠っています。
  週・月では、「何時によく使うか」（0〜23時）も出ます。使うほど、おばけが大きくなります。
  グラフの量は、週（月）の枠の使用%が増えた分です。1%ずつの記録なので、少しの量は、まとめて出ます。時間ごとの記録は、この機能を入れた版から始まります。

記録から言えることだけを、提案として出します（下のプランで足りる可能性、制限が続いている、5時間枠の始め方、週の枠の使い残し）。
記録は Mac の中（`~/Library/Application Support/Cooltime/history.json`）だけに保存し、会話の中身は記録しません。記録は、この機能を入れた時点から始まります。

## キャラクター

メニューバーには、お化けの体に動物の耳をつけたキャラクターと、一番大事な1つの数字を出します。
キャラクターは、うさぎ・ねこ・くま・ぶた・かえるの5種類で、管理画面の「キャラクター」で選びます（既定: うさぎ）。

| 状態 | 数字 | 形 | 動き |
|---|---|---|---|
| 制限中 | 一番早く戻るものの時間（「あと43分」。1日以上は「あと2日」） | 耳が縮み、目を閉じ、右上に「z」 | ゆっくり上下に浮く |
| 制限なし | 5時間枠など短い枠の、残りが最も少ないもの（「残り87%」）。週・月の枠は、残りが10%を切ったときだけ、それを優先して出す（「週残り9%」） | 耳が立ち、目が開いている | きょろきょろ + まばたき |
| すべて取得に失敗 | なし（キャラクターだけ） | 耳が崩れ、目が「×」 | ほぼ止まる。ときどきぷるっと震える |

- 取得に失敗しているもの、目安を過ぎたもの、まだ取れていないものの数字は、メニューバーには使いません（古い数字を出さないため）。
- メニューバーが混んで Cooltime が隠れるときは、管理画面「表示の設定」の「メニューバーの幅」で、せまくできます（アイコンなし・「残り65%」→「65%」）。位置は、Command キーを押しながらドラッグして、動かせます。アイコンが隠れて見えないときは、アプリをもう一度開く（Finder でダブルクリック）と、管理画面が開きます。
- 数字の前に、そのもとのサービスのアプリのアイコン（Claude や ChatGPT など）を添えます。アプリが入っていないサービスは、頭文字を出します。
- アイコンをクリックすると出るポップオーバーには、枠ごとの**おばけ散歩**（おばけが、残りの位置にいる。右＝たっぷり、左＝尽きた。残り10%未満は、あたふた。尽きると眠る）と、「残り87% · 17:20 リセット」を出します。リセットの書き方は、管理画面の「表示の設定」で、日時（既定）か、「あと4時間12分」かを選べます（「明日」「今夜」は使いません）。
- 動き: 管理画面で「動く／ときどきだけ／止める」を選べます。

### 描き方（理由）

**コードで描きます**（Core Graphics）。絵は `characters/menubar/*.svg` を、`scripts/gen_characters.py` で
「M / L / C / Z だけのパスの列」に変換して、`Sources/Cooltime/CharacterData.swift` に持たせています（自動生成。直接は編集しません）。

- 動きの数値（`characters/motion.json`）を、そのまま使えます。5種類 × 3状態を、1つの描画コードで持てます。
- 画像を書き出す方法は、コマ数が増えます（「制限なし」は、見回しの5秒と、まばたきの3.4秒が重なる）。絵や動きを直すたびに、書き出し直しも要ります。
- SVG を実行時に読む方法は、XML と円弧の計算が実行時に要ります。変換は開発時に1回だけにして、実行時は、パスを塗るだけにしました。
- 変換が元の絵と合っているかは、15枚すべてを、元の SVG と描き比べて確かめました（違う画素は 1% 未満）。
- 絵や動きを変えたら: `python3 scripts/gen_characters.py`（種類を増やすときは、スクリプトの `ORDER` と `NAMES` に足します）。

メニューバーは `NSStatusItem` で出しています（`MenuBarExtra` のラベルは、動きが安定しないことがあるため）。
画像は 1 色のテンプレート画像で、ライト／ダークに自動で合います。目・鼻・口は、透明にくり抜いて描きます。

### 電池への配慮

- 画面の書き換えは 1 秒に 8 コマまで。コマごとの画像は使い回します。
- 画面がスリープしているとき、メニューバーが隠れているときは、タイマーごと止めます。
- 「低電力モード」のときは、まばたきだけ（それ以外は静止）。管理画面の「低電力モードのときも動かす」で、フルに動かせます（既定はオフ）。
  見回す動きが出ないときは、まず低電力モードを疑ってください。管理画面の「キャラクター」に、止まっている理由が出ます。
- 「視差効果を減らす」がオンのときは、静止。

### 18pt での見え方（確認の状況）

- **シミュレーション**（Linux 上で、同じ形を 36px = 18pt の2倍、と 18px に縮めて描いた確認）:
  - 36px（Retina の実寸）: 3つの状態は、ひと目で見分けられました。目の形（開く／閉じる／×）と、「z」、耳の形（立つ／縮む／崩れる）が、はっきり見えます。5種類のどれも同じです。
  - 18px（1倍の画面）: 目は細かくて潰れ気味ですが、「z」と耳の形で、制限中と失敗は見分けられました。ねこ・ぶたの制限中と失敗は、近く見えます。
- **実機（Mac のメニューバー）での確認: 未確認です。** 作成した環境が Mac ではなく、メニューバーに出したところを、まだ誰も見ていません。
  確認してほしい点: 3つの状態の見分け、ライト／ダークで目・鼻が見えるか、ぶた・くまの鼻とかえるの目のリングが潰れていないか。

## 守っていること

- 戻り時刻は**公式の値だけ**を使います。目安を過ぎても「戻った」とは決めず、「リセット目安です。必要なら再確認してください」と出します。
- APIキーは **Keychain にだけ**保存します（ファイル・ログ・画面には出しません）。
- 自動検出は、ファイルがあるかを見るだけです（通信なし）。読むのは、メールアドレス・プラン名だけで、トークンやパスワードは読みません。
  通信するのは、Codex と Claude Code の /usage（どちらも1分おき。Claude は返事が終わった合図のときも）と、更新ボタンのときだけです。APIキー系は、更新ボタンのときだけです。
- 他のツールの設定（Claude Code の settings.json）は、内容を見せて同意を得たときだけ、バックアップを取って書き換えます。
- 通信先は各サービスの公式の窓口だけです。分析用の送信はしません。データは Mac の中（`~/Library/Application Support/Cooltime/`）にだけ保存します。
- アプリの中でログインや支払いはしません。支払いは、支払いページを既定のブラウザで開くだけです。
- 画面の読み取り・Cookie・スクレイピングなど、規約に反しかねない方法は使っていません。
- 時刻は常にこの Mac のタイムゾーン。動きは最小限で、くるくる回る表示はありません。

## 実機で確認が必要なところ

作成環境が Mac ではなかったため、次は未確認です。動かして、ずれていたら教えてください。

- Claude Code のステータスラインの JSON 項目名と、`~/.claude.json` の `oauthAccount.emailAddress`（`rate_limits.five_hour.used_percentage` / `resets_at`）。
- Codex の `account/rateLimits/read`・`account/read` の応答の項目名と、起動方法（ログインシェル経由で `codex app-server`）。
- 各 API の応答の項目名（テストは公式ドキュメントの形を元にしています）。
- メニューバーのカプセル表示の見え方（ライト／ダーク）。

## 開発

```bash
swift test                 # 時計を差し替えるテスト（時刻の計算・状態の判定・応答の読み取り・設定ファイルの書き換え）
scripts/build-app.sh       # build/Cooltime.app と build/Cooltime.zip を作る
```

構成: `Sources/CooltimeCore`（画面に依存しない計算・読み取り）と `Sources/Cooltime`（SwiftUI アプリ）。
サービスの追加は `Catalog.swift` と、`Parsers.swift` / `Fetchers.swift` に足します。
非公式な取得方法を足す場合は、既定オフの「実験的」として、確認画面つきで追加する前提です（今回は仕組みのみで、実装は入れていません）。
